# PCB 设计指导：14S 电机驱动板

2026-09-08。依据 [来源目录](SOURCES.md) 整理成协作规则。这里约束后续布局与审查，不表示已经读取并修改了当前 PCB。

电机功率级的详细执行入口现位于 [motor-power-stage-layout Skill](../skills/motor-power-stage-layout/SKILL.md)。其配套文档展开到引脚/焊盘、回路、Kelvin 取点、预充状态、铜皮瓶颈、热与装配，并提供预算示例和分层验收。本页保留项目总体约束，具体操作以当前数据和专项指引共同核对。

## 设计输入

| 输入 | 当前已知 / 处理方式 |
|---|---|
| 电源 | 用户确认 14S，满充 58.8V；回灌和瞬态上限仍需结合实际电源/BMS/保护确定 |
| 铜厚与散热 | 用户希望 2oz、散热片；各层实际铜厚、孔铜和热接触条件尚待确定 |
| 电流 | 电机未选定，200N·m 是减速器输出短时峰值；不能据此直接给出相电流和 PCB 载流额定 |
| 机械 | 板框、安装孔、插头方向、散热器、电解卧倒空间及磁铁位置需要真实尺寸 |
| 实际器件 | 从当前网表/BOM 确认主控、驱动、MOS 和封装，不能把旧工程型号套入当前工程 |
| 制造 | 选定层叠、铜厚、工艺选项和装配方式后，才生成可执行 DRC 配置 |

本板的工作电压、制造下限和热/电流限制是不同约束，分别记录。资料有冲突时优先核对真实器件修订和订单工艺，不从社区默认值中挑一个直接应用。

## 布局和回流

TI SLVA959B 的 §§2–7 提供电机驱动的回路与热设计依据。结合本项目，采用以下检查项；具体数值另行计算，不从示例图照抄。[M01](https://www.ti.com/lit/an/slva959b/slva959b.pdf)

| 检查项 | 要得到的结果 |
|---|---|
| 半桥与本地旁路 | 高频换流路径紧凑；大电解承担储能时，MOS 附近仍按器件要求保留高频旁路 |
| 栅极回路 | 驱动输出、栅极电阻、MOS 及源极返回构成短回路，避免与大电流铜段共用高阻抗返回 |
| 分流采样 | 从分流电阻测量端分别引出 Kelvin 线，采样对并行、对称，避开开关节点；滤波靠近采样前端 |
| 电源与地 | 识别功率回流和安静模拟参考，检查地平面颈缩/开槽；不按 AGND/PGND 名字盲目切割整个参考面 |
| 过孔和散热 | 检查跨层电流瓶颈及热传导路径，采用实际孔铜、铜厚和散热结构，不按过孔个数直接给额定 |

若实际采用 DRV8350/8353 系列，另核对对应变体的 §11：VM/VCP/CP 等外围位置、GHA/GLA 等驱动与返回路径，以及适用变体的采样引脚。DRV8350 与带 CSA 的 DRV8353 不可按同一采样引脚表处理；带降压的 R 变体又有额外布局要求。[M02](https://www.ti.com/lit/ds/symlink/drv8350.pdf)

## 先定功能和机械约束，再排布

1. 先锁定板框、孔、端子、散热接触面及编码器机械中心。
2. 按输入保护/预充、母线电容、三相功率级、驱动、采样、辅助电源、主控与接口划分功能组；具体保留哪些块以当前原理图为准。
3. 在功率组内完成回路约束，再放其他模块。自动分组可以帮助找到相关器件，不能替代这一电气次序。
4. 把器件本体、焊盘、丝印、插头护套、插拔空间和散热器分别建模。底面器件与顶面器件二维重合不一定冲突，也不能据此认定三维无冲突。
5. 放置 keepout、走线/过孔限制和铜皮 keepout 分开处理，不因一个工具接受了“区域”参数就假设三者都生效。

对应参考：官方 O01/O06，社区 C02/C03/C04。C03 的分组规划有矩形/分次碰撞检查简化，C04 明确区分放置约束和铜皮约束；这些限制需在适配层补充。[C03](https://github.com/oaslananka/easyeda-mcp-pro/blob/68c86fa7ef7d0b013ed6cc588727eca3baf0e1c9/src/pcb-layout/floorplan.ts)、[C04](https://github.com/biosshot/easyeda-copilot/blob/bf10f7f9c80156abdbf80c45860051026e74b799/mcp/docs/pcb-layout/mechanical-validation.md)

## DRC 与工程规则的分工

制造规则核对线宽/间距、孔径/焊环、铜到板边、阻焊、丝印和装配要求。JLCPCB 本次所查铜厚指南列出 2oz FR4 的最小线宽/间距为 0.16mm；这是工艺资料中的下限，不能当相线宽度或耐压间距，最终以订单工艺为准。[M03](https://jlcpcb.com/help/article/jlcpcb-copper-weight)

嘉立创规则管理可以配置默认/专用规则，约束区域还能覆盖区域内的布线、过孔和间距要求。写入前列清目标网络、规则优先级、单位及预期差异，写后回读实际分配。[M04](https://prodocs.lceda.cn/cn/pcb/design-design-rule/)、[M05](https://prodocs.lceda.cn/cn/pcb/place-constraint-region/)

本板至少区分母线/相线、栅极与返回、采样差分、模拟电源、数字电源、通信及普通信号。低频电流采样的成对布线要求不代表应随意套用高速链路的固定阻抗值。DRC 通过仍需单独检查功率回路、热、回灌和机械装配。

## 选型必须连同 PCB 条件审查

以下是本项目的输入清单，不是具体器件已通过选型的结论。参数应来自实际型号的规格书及供应商数据，BOM 工具负责定位缺项与关联，不替代工程计算。

| 器件 | 必须补齐的证据 |
|---|---|
| MOS | VDS 与实际瞬态、VGS 与驱动、工作温度/栅压下 RDS(on)、栅电荷和开关损耗、SOA、封装热路径、真实引脚映射 |
| 母线电容 | 耐压、纹波电流/ESR、温度寿命、有效容量、机械固定和连接电感；不能只按每微法价格替代 |
| 分流电阻/放大器 | 峰值与 RMS 电流、脉冲/连续耗散、容差/TCR、采样范围、输入共模和过载；与 Kelvin 焊盘布局配套 |
| 降压/LDO | 输入边界、各路负载、损耗及热条件、压差、环路/输出电容要求；不能只看标称输出电流 |
| 接口与保护 | 连接器/端子接触温升、线缆、保护器件钳位与寄生路径、MCU 电平及编码器供电；关联真实装配方式 |
| 所有采购件 | MPN、供应商编号、封装与管脚映射、价格数量档/时间、库存及替代验证状态；同名匹配后仍逐项核验 |

C05 可参考缺料号/封装/供应商信息的结构化报告；O08 涉及属性或整件替换，操作前后必须比较 UID、封装及引脚网络。H01 的机器人硬件只作拓扑和布局入口，不把其器件额定直接移植到 14S。
