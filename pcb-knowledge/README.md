# PCB 专题：布局、选型与规则

核对日期：2026-09-08。用户要求以 PCB 为重点，本目录补齐此前偏重 MCP 接口、缺少板级设计依据的问题。这里收录的是可检索的来源、审查结论和后续工具要求；未在现场 PCB 上启用新的扩展。

需要直接使用电机功率级布局流程时，读取 [专项 Skill](../skills/motor-power-stage-layout/SKILL.md)。专题资料索引与可调用 Skill 现在分别有明确入口；Skill 没有把社区扩展自动装入编辑器。

## 原来收录到什么程度

原 40 项待办中，F01–F05 涵盖 PCB 调查、原理图同步、网络分类/DRC、焊盘锚点和受约束布线，C07 涵盖预览；E01–E05 涵盖采购、BOM、ERC、电源树和仿真。这些仍是 `proposed_not_deployed`，不是已运行的 PCB 设计规则引擎。

本次新增专题把官方扩展、社区工程规则、器件厂商指南、制造要求和机器人硬件分开索引。固定提交、发行版本、审查范围与限制见 [来源目录](catalog.json) 和 [可读来源表](SOURCES.md)。

## 最有用的补充

| 优先级 | 资料 / 工具 | 对我们实际有什么帮助 | 使用边界 |
|---|---|---|---|
| 1 | 官方 PCB 器件分组器 O01 | 从原理图页或功能框识别模块，把零散 PCB 器件整理成组 | 分组只是布局起点；它不计算功率回路质量。源码备份仅保留最近一次，接入时需另存版本化检查点 |
| 1 | 官方 Gerber 转 SVG O05、设计报告 O04 | 查看实际制造层图，导出网络长度和焊盘位置，定位遗漏和方向错误 | 需要校验单位、层/镜像、导出时间和工程哈希；SVG 的网络标注还包含画布来源信息 |
| 1 | TI 电机驱动布局指南 M01、DRV835x 规格书 M02 | 明确旁路、栅极回路、分流采样、地回流和散热的布局重点 | 最终按实际驱动芯片及电流条件选择章节；不能套用不同变体的脚号和外围 |
| 1 | 社区 PCB 规则手册 C01、布局约束 C02/C03 | 有结构的检查清单，含封装外框、板边、装配、测试点和规则报告 | 默认数值、按名字分类、矩形近似都需校核，不能直接作为 14S 功率板标准 |
| 2 | 官方规则生成器 O02 | 按叠层和网络类别生成线宽/间距候选；包含载流估算代码 | RBF 阻抗模型需与真实叠层和厂商计算器对照；网络名推断不是电气事实 |
| 2 | 官方 PADEN WASM O03 | 对铜皮、过孔和负载做供电网络分析，观察压降与电流/功率密度 | 要有正确铜厚、几何、源和负载；功率密度图不等于温度场，不能代替开关瞬态、EMI 或整板电流额定验证 |
| 2 | 官方 FreeCAD 协同 O06、社区机械检查 C04 | 检查散热片、卧倒电解、插头、螺钉、磁铁与编码器的空间关系 | 双向同步会改变位置；需要真实尺寸。放置禁区与铜皮禁区分别建模 |
| 2 | 交互 BOM O07/O09/C07、属性更新 O08、BOM 质量 C05 | BOM 与板上位号联动，发现漏料、封装不符和装配定位问题 | 同名/同封装不能自动认定电气兼容；整件替换可能改变引脚映射和 PCB 关联 |
| 参考样板 | mjbots/moteus H01 | 定位机器人电机驱动的原理图、PCB 与设计说明 | 已查 README/设计说明和文件树，尚未逐层审查铜皮。其板型电压不能直接覆盖本项目 58.8V |

以上判断是我们对固定版本材料的适配评估；每项原始链接见来源表。本轮未执行上游扩展或求解器。

## 三类不能直接照抄的数字或结论

1. C01 手册的普通信号默认线宽与其 2oz 制造下限存在条件差异，所谓“大电流”默认线宽也不能代表电机相线。先绑定铜厚、层别、允许温升和电流，再计算；不把通用表格当本板额定。
2. O02 的载流模块使用 IPC-2221 形式的经验计算并要求温升、长度和铜厚等输入；仓库作者对阻抗代理模型有误差说明。接入后也只能给出带条件的估算。
3. moteus 根 README 的 n1 输入上限为 54V，而历史 `hw/n1/DESIGN.md` 写 51V；不同文档/板卡修订不能混用。GitHub 最新 Release 是客户端软件发行，不等于最新 PCB 修订。两者都不能直接拿来通过 14S 满充 58.8V 的审核。

## 如何调用

```powershell
node tools/reference-hub.mjs topics PCB

node tools/reference-hub.mjs read easyeda/eext-pcb-component-grouping src/source/source-grouping.ts 1
```

`topics` 返回筛选后的参考及固定链接，不执行参考中的命令。`read` 按上游版本目录取得文本。专题来源拥有自身固定 SHA；若今后上游目录更新，先对照 SHA 再使用 `read`，历史原文以专题固定 URL 为准。

## 接下来应实现的 PCB 功能

1. 只读板级快照：工程/板 UUID、板框、层叠、器件/焊盘、网络、规则、铺铜和制造层图；绑定同一版本。
2. 从原理图功能组映射 PCB 对象：保留 UID，锁定接口、安装孔、功率管和散热器等机械约束；只预演布局差异。
3. 对本项目检查功率回路、采样与回流、铜皮瓶颈、料号/封装和装配空间；未知输入明确列出，不硬凑通过分数。
4. 在现有未知写入/任务恢复缺陷修复后，再接入布局写入和规则应用，并验证铜皮、焊盘网络及制造输出。

实际设计规则见 [PCB 设计指导](PCB-DESIGN-GUIDE.md)。资料更新用 `build-catalog.mjs`，检查用 `verify.mjs`；生成器重新锁定所选来源时应审查 SHA 差异。
