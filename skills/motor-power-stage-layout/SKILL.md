# 电机功率级 PCB 布局

把电气回路、机械约束和可验证的修改绑定起来。目标是产出能执行、能核查的布局方案或整改结果，而不是把器件排得整齐后宣布完成。

## 先判断任务范围

- 用户只问方案或 Skill：完成资料、规则与说明，不操作现场 PCB。
- 用户要求检查：读取当前设计，给出有定位证据的问题；不能只看原理图就声称 PCB 回路合格。
- 用户要求整改：在已有授权内完成相关修改和回读，不反复索要逐步确认。缺少关键输入时先做独立可完成的部分，只询问会改变决策的参数。
- 操作嘉立创时同时使用已安装的 `easyeda-api` Skill，读取真实版本方法定义；本 Skill 不提供虚构的 EDA 方法，也不启动另一套 Bridge。

## 执行顺序

1. **确定当前对象。** 记录工程/板 UUID、版本和保存时间，取得相互一致的网表、BOM、封装、叠层及 PCB 几何；已有上下文能确认的参数沿用，不把历史料号当当前事实。
2. **确认拓扑。** 标出三相开关节点、每个 MOS 的 D/G/S、驱动返回、分流电阻两端、本地电容和预充旁路。先修短路、错脚、开路和错误封装映射，再优化位置。
3. **明确机械边界。** 已确认的板框、固定孔、端子、编码器中心、散热接触面和器件高度优先；未确认条件标为暂定及其影响，继续可逆候选。保护与供电位置不能仅按原理图从左到右机械照搬。
4. **共同规划全板。** 把三相、共享驱动、输入/储能、相线出口、采样到ADC、辅助电源与机构放在同一布局中。大件预留还需包含其关键外围、铜路和返回空间；先前放置的一相只是可调整的候选。重大重排保留电气取舍不同的对照，不以功率区外接矩形最小或三相完全对称选定方案。
5. **用关键通道反推位置。** 以实际焊盘同时预演本地换流、最差栅极去回、Kelvin及去耦返回，再细化相单元并逐相核查邻相影响。存在一条可通折线只证明几何可达；候选可继续可逆试放，但决定定稿前须用适用层/宽/孔和完整返回评估质量。出现拥堵时一起移动驱动、相单元或外围，不把所有问题留给最后布线。
6. **检查层、热和装配。** 重铺铜后逐层检查连接与断颈、跨层电流、散热界面、丝印/测试点、插拔与螺钉空间。
7. **按证据交付。** 独立回读、保存/导出、图面、原生 DRC、板级工程检查及实测分别报告。不把工具调用成功等同于这些检查全部通过。

## 决策约束

- 不以“2oz”“120V MOS”“200N·m”“DRC 通过”任一条件直接给整板连续/峰值电流额定。相电流、电池电流、单管电流及电阻实际波形分别计算。
- 不为高电流网络套固定线宽，不给每个过孔固定安培数。制造下限与电气间距、压降、温升是不同约束。
- 不把 G-S 电容叫母线旁路，不把 VDS 额定当 VGS 额定；钳位对象和实际返回点必须明确。
- 不把 DRV8350、DRV8353、带 R 的型号视为同一引脚/功能集合；芯片名字相似不能支持整件替换。
- 不按 AGND/PGND 字样盲目切割参考面，不让敏感信号跨无回流路径的缝隙；实际参考连接以芯片手册和电流路径决定。
- 不把 LTC7001 的栅极斜率控制当作完整预充状态机，也不为了“完善保护”无依据地叠加芯片。每项必需功能有明确承担者即可。
- 不用自动分组、矩形碰撞或静态功率密度图替代回路、真实铜形、温度和 EMI 检查。
- 不把底面空白视为无代价空间。翻面同时检查跨层闭环、参考面、热梯度、装配高度和散热接触；未确认叠层的跨层方案保持候选状态。
- 位号先预留、保持近旁可读；一致排版服从实际引脚与电气回路。不要为了相同偏移加长栅极支路，先检查标注候选和完整侧边空间。
- 重复相单元保持相同的功能对应和阅读规则，按热边界及最差去回路径解释必要错位。接口按用户的线束组安排；以厂家机械图确认插拔方向，板上旋转角不能代替三维朝向。直焊焊盘须连同实际焊盘中心、相网映射、阻焊、焊线和应力释放空间审查，具体方法见[铜皮、热与机械](references/copper-thermal-mechanics.md)。
- 不因 API 超时而重试创建；未知写入先查明实际状态。现有仓库的已知问题不能由本 Skill 的文字规则宣称修复。

## 交付内容

按任务大小给出适量内容，至少包含：当前设计与输入依据；问题所在位号/焊盘/网络/层；必要修改及原因；已完成的验证；未确认参数和剩余工作。布局方案补充功能分区、关键回路、禁止跨越区域与实际约束值来源。

发现新错误时追加当前项目的 Markdown 错误记录，保留编号，区分现场发生、静态确认和假设。本 API 仓库使用 `docs/ERROR-LOG.md`；避免为同一项目创建多个互不一致的记录。

复盘形成两层记录：项目反思保留具体版本、失败判断和证据；Skill只提炼会改变下一次决策的方法。更新结论时同步当前入口和仍被引用的摘要，保留历史原始数据，防止旧失败孔例继续被复制。
