# 母线电容、预充与回灌

## 电容按职责与应力审查

| 职责 | 需要的证据 | 布局和成本取舍 |
|---|---|---|
| 母线储能 | 母线纹波、负载/回灌工况、有效容值、额定电压、ESR、纹波电流及寿命温度 | 直插/卧倒电解可以降成本；核查高度、固定、引线寄生和与热源距离 |
| 半桥本地高频旁路 | 电容到功率器件及返回的完整回路、开关边沿、实际阻抗 | 大电解不能只按标称容值等量替代该功能；从所需阻抗和局部路径决定器件组合 |
| 驱动电源/电荷泵 | 实际芯片要求的引脚对、容值、偏压、耐压和位置 | 不与跨母线电容混淆，不因电源网名相同就放到远处 |
| 栅极电容/RC 吸收 | 跨接节点、开关损耗与实测波形 | 属于调节/抑制网络；没有依据不默认增加或加大 |

DC 电机的母线电容应用笔记可用于理解电流、纹波及储能关系，但其简化负载和 PWM 公式不能直接视为三相逆变器所有工况的结果。实际三相电容 RMS 电流还取决于调制、负载和回流。[TI SLVAFT0](https://www.ti.com/lit/an/slvaft0/slvaft0.pdf)

X5R/X7R 等高介电常数 MLCC 应查实际料号的 DC 偏压曲线；标称耐压内工作不代表仍有标称容值。将偏压、温度和容差纳入有效容值预算，而不是统一乘一个无来源的折扣。[Murata DC 偏压说明](https://www.murata.com/en-us/support/faqs/capacitor/ceramiccapacitor/char/0005)

降成本的交付应列 `原料号/职责 → 候选料号/有效参数 → 单价数量阶梯与查询日 → 封装/固定变化 → 已核对项目`。价格必须当日查询，不把低价当电气等效依据。14S 满充 58.8V 只是一个工作点，不能据此直接批准 63V 电解、TVS 或驱动输入范围。

## 先辨别预充拓扑

| 拓扑 | 限流承担者 | 主要验证 |
|---|---|---|
| 电阻预充＋主旁路 | 串联预充电阻承担充电能量；主开关在压差合格后旁路 | 电阻脉冲曲线、重复启动、压差检测、超时、开关默认态及旁路时冲击 |
| MOS 线性斜率控制 | MOS 在线性区承担应力，栅极驱动设置输出上升 | 全过程 VDS/ID/时间、热态 SOA、负载短路和重试，不能仅看 RDS(on) |

不得将两者的公式和元件职责混用。若当前工程用电阻支路，优先完善该方案已有的检测和状态机，不能仅为减少芯片就改成尚未验证 SOA 的线性方案。

LTC7001 具有静态高侧 N-MOS 驱动、电荷泵及斜率控制应用，也有相应欠压/过压相关功能；它并不自动完成用户所要求的母线压差判定、超时和重试状态机。驱动外围须按 Rev G 的具体连接及条件核查，不能泛称“只会开关”或“单芯片已包含所有预充保护”。[LTC7001 Rev G，应用信息及 Figures 5–7](https://www.analog.com/media/en/technical-documentation/data-sheets/ltc7001.pdf)

## 电阻预充的最小功能分配

先从当前设计填写下表，允许 MCU 承担判断和计时，但明确它失电或复位时的硬件状态。下表是功能要求，不是要求每行增加一颗芯片。

| 功能 | 应有的连接/行为证据 |
|---|---|
| 控制电源 | 预充开始前控制与检测电源已可用；若主旁路未开就无法供电，会形成启动死锁 |
| 默认关断 | 上电、GPIO 高阻、MCU 复位、欠压时主旁路不会意外开启；栅极有明确放电路径 |
| 电阻充电 | 电流通过预定支路，背靠背器件的体二极管方向没有绕过限流或破坏反接目标 |
| 压差合格 | 读取电池侧与母线侧电压，校验 ADC 合理性；阈值、稳定时间、误差预算和允许旁路冲击有来源 |
| 超时/故障 | 在规定时间内未达到条件就关断预充并保持主旁路关断；限制自动重试和电阻累积发热 |
| 正常旁路 | 只有合格后开启主通道；支路退出顺序不能让母线掉电或重复冲击 |
| 运行/掉电 | 失去控制电源、电池/BMS 断开及电机回灌时的能量路径明确 |

状态可表达为 `OFF → PRECHARGE → READY/RUN`，任一不合格条件进入 `FAULT`；这只是审查模型，实际阈值和计时值不得由此表默认生成。

PCB 上将预充电阻发热区与电解、采样分压、逻辑电源隔开；高压分压器按器件工作电压和间距分段，敏感取样回到正确参考，不直接借用功率颈缩处作为“地”。布局必须能支持真实的输入侧/输出侧电压测量。

## 回灌与过压

预充解决接入时的充电冲击，不能代替运行中的再生能量处理。先确认电池/BMS 能否吸收当前工况，再考虑已有母线储能、制动策略和必要耗能/保护路径。使用能量预算见 [预算示例](budget-examples.md)。

对 TVS 核对工作反向电压、指定脉冲下的钳位、电流、温度和重复能量；把回路寄生造成的额外尖峰计入被保护器件端电压。TVS 不默认承担持续制动功率。对主开关核对体二极管方向与反向能量路径，断开命令不代表所有方向电流都被阻断。

交付分别标记“预充功能已实现”“过压阈值有依据”“回灌能量可承受”和“实测已完成”。缺少其中一项不能用“保护完善”整体概括。
