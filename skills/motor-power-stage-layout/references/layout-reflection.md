# 布局反思录：从整齐的器件阵列回到完整的电路

适用：用户认为功率板散乱、重排后仍有问题，或需要复盘布局方法。源于2026-09-11一次三相关节板重排的实际教训。以下案例数字只属于该次未布线设计，不是其他板的尺寸、字体、工艺或电流标准。

## 我们当时做对了什么，又漏掉了什么

初稿先安置一相，再把其他两相塞进剩余区域，产生方向混乱和空间碎片。重排把六颗MOS变成三列两排，相关52件的外接矩形由约70×60mm收拢到63×37mm，位号也统一了。位置、网络及原生保存核验真实通过。

用户继续指出问题是有依据的：我们改善了器件排列，但还没有证明它与共享驱动、母线、采样、其余功能区形成了更好的整体。主要失误是把容易量化的几何结果放在决策中心，给尚未验证的回路质量留下过多“布线时处理”。

| 已确认事实 | 当时判断的不足 | 下次应改变的决策 |
| --- | --- | --- |
| 只落位52件，152件待布局、2个机械参考；16件大件仅离线预留 | 功率区更小、空白更连续，仍未证明关键外围和连接能同时容纳 | 全板功能与主电流/返回通道共同预演；区分已放置、完整局部单元、大件预留、未知区域 |
| 共享驱动最远栅极入口投影从约33.84变为41.08mm，直线有异网铜障碍 | 为统一阵列接受较差的最远路径，只列作后续约束，没有充分比较驱动相对位置 | 比较最差去回环路、换层与返回环境；共享驱动与三相一起移动和旋转，不机械固定在几何中心或边缘 |
| 模拟去耦供电端投影约1.55mm，AGND存在约9.35mm折返通道 | “有出口”不足以说明供电两端组成了好回路 | 一起评估Kelvin、AGND、REF和去耦，优先改变器件/局部参考结构，而非把狭窄折线当正式走线 |
| 底面器件从1件增加到13件，采样前端靠近分流器背面 | 空间收益有记录，跨层、局部温差、散热面和高度代价没有在选择时获得相同权重 | 对照可用安装面、跨层完整回路与实际热/机械边界；翻面可以合理，但需要理由和条件 |
| 为统一位号移动栅阻，局部支路投影变长；后来又发现标注搜索没有覆盖长器件侧边 | 排版开始反向驱动关键器件位置，工具搜索不足也被当成物理无解 | 先优化标注候选范围和近旁阅读，再只在电气可接受的范围内调整器件；不锁死所有标签的相同偏移 |
| 某相Kelvin孔例通过，其他相旧数据已为零间距，摘要却曾写成三相通过 | 同模板不等于同环境，审查摘要又漏掉了负结果 | 保留逐相、逐层的最差值/失败对象；结论从完整结果集合生成，失败不能被代表相覆盖 |

这些事实支持重新评估布局，不足以证明实际板已经振荡、过热或采样失效；当时没有实际铜路和实测。反思需要承认决策证据不足，也要保留已完成保存与网络核验的事实。

## 以后怎样选择布局

先确定功能关系与功率流向，再选择器件排列。三相阵列是候选形态，单一驱动也不一定必须居中；实际引脚分布、相线出口、散热结构和母线方向决定位置。

重大重排时，对照方案应改变真实取舍，例如驱动相对三相的位置、本地旁路安装面、输入与相线出口方向，或采样前端与ADC的关系。只比较同一阵列的长宽和旋转，无法回答回路有没有变好。改驱动拓扑或MOS型号属于独立设计变更，不能为布局方便静默实施。

| 比较对象 | 能支持选择的证据 | 只能作辅助的指标 |
| --- | --- | --- |
| 换流与母线 | 正负两端路径、供电分叉、实际焊盘进入宽度、跨层连接和相线通道 | 电容离某颗MOS的中心距 |
| 六路栅极 | 每路信号与对应源极返回、最差绕行/换层/共用阻抗及障碍 | 六颗MOS是否排成直线、单根线最短 |
| 模拟链 | 两个真实取样端、输入对、供电两端、AGND/REF到ADC及同时占用空间 | 放大器贴着分流器、某一个孔能放下 |
| 整板与双面 | 输入/储能、Buck热回路/反馈、MCU去耦/时钟及接口的完整关键器件簇，连同返回和装配空间 | 大件框不重叠、包络面积相加、底面仍有空白 |
| 工艺与热 | 实际层叠、铜/孔、热传导方向、绝缘/接触面、器件高度和局部热梯度 | 层名、外层目标铜厚、封装标称电流 |

在无实际布线时，可以在离线候选中用带宽度/间距/孔尺寸的路径预演判断瓶颈。注明参数来源与适用层，分别叠加所有相关路径和异网铜。细线探针只回答“有没有出口”；若只有紧贴工艺下限的复杂折返，不能把它计为有充分余量的好布局。

关键输入未全时继续可逆候选和独立可完成的工作，写明依赖项；不用假设参数批准载流、热或投板，也不必等待全部实测才能进行位置探索。若约束变化，及时解锁依赖它的位置。

取舍不要求新方案的每一项指标都优于旧方案。某些路径可以变长或增加换层，只要在本板约束下有支持其可接受性的证据、收益清楚、代价被显式比较；没有通用加权总分。未知项会限制定稿范围，不应被自动写成已失败或无限期停止全部探索。

## 位号、MOS封装与专业感

专业感来自功能块的组织、可解释的方向、自然的电流通路和清楚的检修标识。重复相单元尽量一致；需要错位时用真实引脚/回路解释。正常字号与近旁标注是要求，特定45mil字号和完全相同偏移只是上述案例的设置。

MOS是否过大要连同真实库焊盘、散热铜、驱动能力、制造和壳体检查。更小本体不等于更小热区域。若已发现现用封装与厂家推荐焊盘不同，应在反复细排前确认该差异是否影响器件间距和热接触；记录差异不等于认定不可焊。电流/热条件不足时保留对照，既不仓促替料，也不把既有大封装当作永远不可挑战的前提。

## 证据如何防止再次误导

- 把“位置/网络/保存核验通过”“关键回路候选可达”“工程布局认可”“实际布线/制造/实测通过”分开。不按检查数量多少合并为“布局通过”。
- 同一模板复制后逐相检查，尤其检查邻相栅阻、分流器、通孔和返回的同时占用。对过孔既检查孔环跨越的铜层，也检查后续连入路径。
- 新候选使相关路径证据失效时，重算受影响对象；原数据保留版本，当前正文不得沿用旧净距。负结果与修正原因必须进入摘要。
- 同时提供顶面、底面和全板功能预留视图。局部对比图保留，但明确没显示哪些器件；分层视图避免把上下投影误读为实际短路或免费空间。渲染图与原生图分别标来源。
- 用户再次认为不合理时，回到决策依据和最差瓶颈审查；不能只增加排列规则或引用更多手册来证明原决定正确。

## 补充反思：封装丝印与主控外围不能被漏查

后续原生图面中，C47/C77的焊盘和器件本体虽未相交，两者封装自带的顶层丝印轮廓却发生了重合。只比较焊盘净距、本体与位号文字，仍会漏掉用户直观看到的元件混叠。审查应分别覆盖同层焊盘、本体、封装自带丝印、位号/数值，以及不同面的热和机械投影；图面发现异常时回读真实库图形，不用某个简化包络检查通过来否认问题。

驱动位置变化后，应共同落实主控的必要外围和连接出口。孤立MCU大件预留不等于主控核心已落位；仍在板外待排的飞线不代表最终布线长度，但这也不能成为推迟整组摆放的理由。把各供电/参考脚去耦、晶振与负载、复位/启动配置和必要地连接一起纳入候选，用实际PWM、SPI、使能及故障引脚选择方向和通道。修正位号时只动明确的文字对象，避免为排版搬动栅阻或扩大电气变更。

## 补充反思：不能用短栅极路径抵消未处理的热源投影

本项目随后把DRV与本地电容移到MOS阵列背面，六组去回端点投影总长变短，位置、网表和保存核验通过，但用户指出驱动位于MOS下面会受热。这次取舍把“热耦合仍待验证”留作后续事项，却在尚无热边界和热路径证据时优先接受了直接上下重叠，决策顺序不妥。

上下两面不碰撞不等于热上互不影响。布局比较应先叠加MOS本体、功率焊盘与计划散热铜，再检查DRV裸露焊盘、本地电容及电解电容的位置；同时考虑高温电感、Buck和散热器安装面。用户明确要求驱动避开MOS下方时，这就是当前候选的边界，不能仅以“栅极更短”继续保留。更换区域可以接受部分栅极路径变长，但须继续检查对应源极返回、本地旁路与实际可布通空间。

记录应区分“避免直接投影”“设置规划余量”和“热验证合格”。例如离线搜索采用2mm几何外扩只是本次筛选条件，不是TI规定的热安全距离，也不能据此推算温升。同一块PCB仍会传热，最终需按实际功耗、铜与热孔、环境和装配条件验证。没有实测不能声称旧布局已经过热，也不能把新位置称作已实现热隔离。

依据重核于2026-09-11：[TI SLVA959B](https://www.ti.com/lit/an/slva959b/slva959b.pdf)第4–7节；[DRV8350数据手册](https://www.ti.com/lit/ds/symlink/drv8350.pdf)实际变体布局；[INA181数据手册](https://www.ti.com/lit/ds/symlink/ina181.pdf)第8.4节。这些资料支持完整回路、旁路及采样原则；本页的案例判断和工作顺序是本次复盘形成的方法，不是TI规定的固定布局或毫米阈值。


### 丝印的两点直线和线宽不可漏查

`POLY`只有两个点也可能是实际生产丝印，不能因不能构成多边形而丢弃。封装常由多条独立直线、圆弧组成，应按全部路径与各自线宽进行线段/线段、线段/铜形、线段/本体检查。碰撞距离扣除对应半线宽；包围盒只作粗筛。案例：两颗10 mil线宽的电容丝印中心线间距0.22 mm，油墨仍可能重叠；字框离6 mil丝印中心线0.006 mm也不是可读空隙。任何没有覆盖这些几何的旧“真实轮廓PASS”均需撤回并重验。保存前绑定最终位置哈希，保存后查看原生画布/制造层。

### 整板优先需要改变实际执行次序

当整板仍有模块未安排而用户要求整体分区时，先交付覆盖全部器件的双面模块范围和关键通道，再继续局部精调。已经保存的小组是可修改候选，不天然成为其他模块必须绕开的冻结边界。输入大电容、保护件、相线焊接端子和两路辅助电源必须按完整真实占位加入，不能用单个芯片或大件框替代完整模块。

并联双接口不等于相反两侧接口，也不等于同边一字排列；按实际板槽和线束空间比较主干。有限种子搜索失败不能证明需要扩板。扩大机械边界、翻面分流主电流、移动编码器轴心都改变工程取舍，应先比较保持既有机械和主要电流路径的方案。

阶段交付分别记录宏分区、锚点落位、外围精排和实际布线；只把确实写入并回读的器件计入已摆放数量。新阶段使用独立证据目录，保留旧阶段的保存和网表核验事实，同时明确尚未完成的图面、布线、制造和实测项目。
### 分组通过后仍需全板机械复核

局部铜形与丝印检查通过，不能直接升级为整批可写。合并候选必须再次覆盖真实板框/孔槽、保留轴位与编码器的双面机械包络、通孔焊脚对两面的焊盘和本体，以及所有已安排元件。底面 TVS 未碰铜，却侵入顶面编码器保留包络，就是分面筛选漏掉机械约束的例子；应撤回该候选的 PASS 并修改坐标，不应删掉保留区来让检查通过。

先证明用于几何分析的基线位置与当前保存源码一致，再将完整联合审查结果绑定最终候选哈希。记录每种检查实际覆盖的对象，不能让单项 PASS 掩盖另一项未检查或失败。搜索采用有限种子、缓存不变几何和包围盒快速排除，避免无界组合搜索拖延实际布局。
