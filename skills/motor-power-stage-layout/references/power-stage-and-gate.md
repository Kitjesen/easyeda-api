# 半桥与栅极布局

## 先分清四类路径

以下是本项目的审查组织方式。换流关注相邻开关状态的电流变化，不能把高低侧 MOS 同时导通画成正常直流路径。

| 路径 | 在 PCB 上实际追踪什么 | 合格证据 |
|---|---|---|
| 高频换流 | 本地电容两端、上下管焊盘、局部回流，以及拓扑中处于该环路的分流电阻 | 标注具体铜层、焊盘、换层点和环路区域；比较修改前后路径 |
| 电机工作电流 | 母线/相线/另一相及电源返回；包含续流和回灌状态 | 不遗漏端子、连接颈、跨层过孔、分流电阻的电流负担 |
| 栅极充放电 | 驱动输出→栅极电阻→G；S/Kelvin S→对应驱动参考 | 出去和返回一起检查，不只比较 GH/GL 的线长 |
| 小信号测量 | 分流测量端→前端→ADC，以及各自参考 | 取点、回流、共模、输出范围与采样时序均明确 |

短而紧凑的换流、驱动与测量路径是 TI 电机布局指南的基础建议；本文件的定位和验收表是针对项目的执行方法。[TI SLVA959B，§§5–7](https://www.ti.com/lit/an/slva959b/slva959b.pdf)

## 先安排三相与驱动，再细化相单元

1. 先结合散热片/端子、输入/相线出口和真实焊盘朝向，共同安排三相与共享驱动的位置及方向；保留辅助电源和采样到ADC的完整关键器件簇及返回空间。再细化上下管、本地母线旁路、分流器和栅极外围，驱动位置可随最差回路反馈调整。
2. 比较候选布局时同时画出电容正端路径和负端路径。电容看起来离上管很近，但负端绕过一排信号器件返回，仍需调整。
3. 以真实焊盘和铜皮评估路径，不能以器件中心间距替代。记录跨层次数和窄颈位置，不给所有封装套“必须小于若干毫米”的标准。
4. 三相共享驱动芯片时，比较六路栅极去回环路及供电回流的最差一路；允许器件朝向不同，不能为视觉镜像牺牲返回路径。候选的可达折线与实际可接受的回路分别判断；重大重排的对照方法见[布局反思](layout-reflection.md)。
5. 复制单相布局后逐相检查网络、封装脚、分流极性、栅极极性、底层铜连接和机械接触，也检查邻相器件对Kelvin孔/AGND/主铜通道的影响。保留每相失败项，不用一相净距概括三相通过。检查 A/B/C 互换及公共铜皮意外相连。

每个关键距离若要成为约束值，填写 `对象两端 / 目标或上限 / 单位 / 来源 / 计算或测量方法`。没有适用数据时写相对位置和待验证范围，不伪造精确限值。

## 栅极、源极与驱动外围

| 检查对象 | 具体操作 | 常见错误和修正方向 |
|---|---|---|
| Rg | 沿驱动到 MOS 的实际支路检查，电阻在所控制的栅极附近，返回也就近 | 电阻靠驱动但其后形成长敏感支路；调整位置并检查开关波形 |
| G-S 下拉 | 确认接到该 MOS 的源极参考和默认关断需求 | 高侧下拉误接 GND；栅极无驱动时行为不确定 |
| G-S 钳位 | 核对极性、漏电、动态钳位电压及负 VGS 条件 | 用 MOS 的 VDS 额定判断栅极保护；应依据 VGS 允许范围和驱动电压 |
| G-S 电容 | 先计算附加驱动负担及对开关时间的作用，再决定是否需要 | 把历史 2.2nF 当万能抗干扰件；不能直接按母线旁路保留 |
| 高侧返回 | 由源极/相节点取对应返回，避免与大电流路径共用不必要的铜段 | GH 很短但返回绕板；同时调整两条路径 |
| 低侧返回 | 根据实际驱动型号及有无分流/独立源极脚确定 | 为“地统一”把返回接到远处电源入口，改变 VGS 和故障检测参考 |
| 驱动供电/电荷泵/自举 | 逐一核对数据手册电容所在引脚对、耐压和回路 | 把不同驱动的自举外围直接复制到带电荷泵型号 |
| VDS/过流检测 | 明确芯片真实检测引脚和 Kelvin 取点；检查 blanking 与阈值 | 借一段功率铜压降当器件 VDS，导致误保护或漏保护 |

DRV835x 应按完整型号、接口和封装核对；DRV8350 不带 DRV8353 的三路 CSA，带 R 的变体另有降压模块。驱动回流、供电电容和检测引脚按实际变体的引脚表、应用与布局章节落实，不在此硬写通用脚号。[DRV835x 数据手册，功能表及 §§10–11](https://www.ti.com/lit/ds/symlink/drv8350.pdf)

## 开关节点与 EMI

在所有相关层标注相节点铜区，检查其与采样对、ADC 参考、编码器、晶振及通信的邻近和上下重叠。相节点必须有足够载流与热扩散面积，但不为“铺满空白”无目的扩大；需要权衡寄生电容、dv/dt 耦合和热路径。不能为减小重叠而随意切断其他敏感信号的参考面。

若预留 RC 吸收焊盘，先明确其跨接节点、回路和元件应力，保持在作用对象附近。是否装配及阻容值取决于实测振铃、损耗和器件余量；不能以“全部补一个吸收网络”替代定位问题。

## 并联 MOS 仅在实际需要时启用

总门电荷与驱动电流、独立栅极电阻、源/漏分配对称性和热耦合必须一起检查。静态 RDS(on) 的均流倾向不保证开关瞬间均分，不能把单管能力简单乘以数量。[TI SLPA020](https://www.ti.com/document-viewer/lit/html/slpa020)

执行上，给每只管列出各自栅极支路和返回、供电入口、到端子的路径及热接触。若位置限制使两管支路明显不等，先比较电感/电阻和温度的最差支路，再选择移动、改变母线分配或减少并联方案；不以增加总铜面积掩盖局部不均。

## 本模块交付

提供一个相单元的分层截图/矢量标注，标出上述四类路径及剩余交叉；表格给出位号、焊盘、网络、层和调整原因。没有真实 PCB 几何时只能交付概念约束，不能填造毫米测量值。
