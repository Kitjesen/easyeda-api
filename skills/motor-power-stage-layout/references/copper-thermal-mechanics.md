# 铜皮、过孔、热与机械

## 从完整电流路径找瓶颈

按 `端子焊盘 → 铜皮 → 窄颈/过孔 → MOS/分流焊盘 → 铜皮 → 端子` 分段，记录层、长度、最窄处、铜厚、孔铜、实际电流波形及热环境。宽阔的中段不能补偿入口只剩一个窄颈。

| 部位 | 必查细节 | 常见误判 |
|---|---|---|
| 功率铜皮 | 实际填充轮廓、开窗/挖空、孤岛、颈缩、跨层连接、可制造性 | 看到整片色块就当它处处同样载流 |
| 焊盘连接 | 端子和 MOS/分流焊盘的有效进入宽度、热焊盘辐条和装配需求 | 线宽很大，但焊盘只用几条细辐条相连 |
| 过孔阵列 | 成品孔径、孔铜厚、孔长、焊环、排列及入口分流 | 每个过孔固定“几安培”，或直接按孔数平均分流 |
| 多层并联 | 各层成品铜厚、连接点、电流分配与连续性 | 四层全部按外层 2oz 计算，或忽略内层不同热条件 |
| 接插件 | 厂家额定条件、接触电阻、针数分流、线径、插拔和温升 | PCB 铜皮足够就认为连接器也足够 |
| 电气间距 | 各网络最大工作/瞬态电压、使用环境、工艺、污染与绝缘要求 | 用工厂最小可生产间距替代电气设计间距 |

JLCPCB 铜厚页面给的是对应工艺的制造能力，订板时还需核对所选产品及工艺选项。不要将某一 2oz 最小线宽/间距直接用于母线或相线设计。[JLCPCB Copper Weight](https://jlcpcb.com/help/article/jlcpcb-copper-weight)

## 计算与分析的边界

可用 `R = ρL/A` 与 `P = I_RMS²R` 对均匀铜段做初算，注明温度和实际截面；复杂铜皮、孔阵列与电流拥挤需要实际几何分析。经验载流计算应注明模型、外/内层、铜厚、允许温升和边界条件，不从输出倒推一个无工况的整板额定。

PADEN 等静态供电分析可辅助发现压降和电流/功率密度集中，但必须检查源/负载边界与网格是否描述真实板。功率密度不是温度，直流结果不代表寄生电感、开关过冲和 EMI 已验证；未运行求解器时不能给伪造热图。

对比布局候选至少保留：最差铜段、端子、分流和 MOS 的损耗估计，输入条件，以及剩余不确定项。不要只按布线总长度或布通率评分。

## 热预算

建立 `器件 → PCB/封装 → 导热界面 → 散热器/空气` 的真实热路径。多只管共享散热器时考虑相互加热及散热器整体温升，不把每只管都当作接到独立的恒温冷板。

RθJA 与测试板和环境有关，不能当封装独有常数直接套到本板。使用 RθJC 时需确认 case 测点、top/bottom 及与实际散热路径的关系；不得把 RθJA、RθJC 和界面热阻不加分析地串加。[TI SPRA953D，RθJA Usage](https://www.ti.com/document-viewer/lit/html/SPRA953D/GUID-431194F1-713D-4677-9761-D96E979DF58D)、[RθJC Application](https://www.ti.com/document-viewer/lit/html/SPRA953D/GUID-29661D81-EC1D-4B48-950E-AC3391D72666)

| 器件 | 输入与损耗重点 | 必须保留的未知项 |
|---|---|---|
| MOS | 实际 VGS/温度下 RDS(on)、各管导通波形、开关/二极管/反向恢复损耗 | 无合适模型或波形时，不把仅导通损耗说成总损耗 |
| 驱动器 | 总门电荷、开关频率、供电损耗和输出级损耗分配 | Qg×V×f 是驱动供能估计，不能全部归于芯片结温 |
| 分流电阻 | 实际 RMS、电阻温升、端子温度、额定和脉冲降额条件 | 峰值时长/周期未知时不能批准峰值能力 |
| 电解电容 | 频率相关 ESR、纹波、热点、与 MOS/预充电阻距离 | 未查纹波/温度寿命，不能只凭耐压和容值批准 |
| 预充电阻/开关 | 每次能量、瞬时功率、重试间隔及故障持续时间 | 电阻名义瓦数或 MOS 标称大电流不覆盖全部应力 |

短时峰值还要用适用脉宽和重复周期的瞬态热阻。归一化 Zθ 曲线需乘对应稳态热阻；已带 K/W 单位的曲线不能再乘一次。初始温度和重复脉冲热积累须明确。[TI SLUAAT8](https://www.ti.com/lit/an/sluaat8/sluaat8.pdf)

线性预充及故障限制还需用实际 VDS、ID、持续时间和温度核对 SOA；不能只用总焦耳数或 25°C 单脉冲曲线批准重复热启动。[TI SLUAAO2](https://www.ti.com/lit/pdf/SLUAAO2)

## 散热片和装配

1. 查封装散热焊盘/金属片属于哪个网络。共用散热片时核查导电路径、绝缘垫/套管、耐压和螺钉接触，不能意外短接不同相节点。
2. 根据真实散热方向选择接触面；塑封顶面、裸露焊盘与器件手册的热参数不是可互换对象。
3. 导热垫厚度、压缩、平面度、接触面积与固定力进入热模型；只写“加散热片”不算完整输入。
4. 热过孔按焊盘、锡膏、填孔/塞孔及装配工艺设计，检查吸锡、焊接空洞和底面空间，不给所有器件统一孔阵列。
5. 卧倒电解留本体、引线弯折、固定与泄压空间；不贴靠高温预充电阻，避免线缆/振动使引线承担全部机械载荷。
6. 板框/安装孔/螺钉垫圈、插头护套/插拔路径、底面器件与外壳、测试探针空间分别检查；二维外框不代替三维干涉。
7. 器件放置禁区、走线/过孔禁区、铜皮禁区独立确认。机械工具返回“无碰撞”不能证明电气铜间距或磁编码器环境合格。

交付一张瓶颈表和热路径表，附真实尺寸/来源、条件化电流估计和待测点。温升/电流额定最终需要匹配工况的样板证据。
