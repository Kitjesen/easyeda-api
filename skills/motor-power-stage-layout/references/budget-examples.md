# 预算示例与公式边界

以下是原创算例，用来检查单位和推理，不是当前板子的额定、最终元件值或保护阈值。计算时使用明确的 SI 单位；缺输入不代填社区默认值。

## 1. 从输出扭矩到电流

在相应机械工况可采用 `T_motor = T_output / (ratio × efficiency)`，然后按电机厂家对 K_t 的定义计算对应电流。K_t 可能采用相峰值、相 RMS 或其他定义，必须对齐控制器电流定义；考虑摩擦、加速度和实际效率模型的适用范围。

只有“减速器输出峰值 200N·m”无法确定电流。即使已知道机械功率，`P/Vbus` 得到的也是有条件的电源侧估计，不能替代低速高扭矩时的相电流预算。

## 2. 分流电阻的幅值与损耗

假设**实际流经某电阻**的 RMS 为 50A、峰值为 80A，电阻为 1mΩ：

- `P = 50² × 0.001 = 2.5W`。
- `V_peak = 80 × 0.001 = 0.080V`。
- 若示例前端 `G = 20`，`Vref = 1.65V`，理想输出在正负峰值时为 3.25V 与 0.05V。

这两个输出非常靠近示例 3.3V ADC 的电源轨；未计前端输出摆幅、误差和瞬态余量，不能据此批准量程。低侧分流的实际 RMS 需由开关状态下的电阻电流取得；上述 50A 不能直接用电机相 RMS 代入。

## 3. 纯电阻预充

仅适用于理想恒定电源、固定 R/C、母线电容初始 0V、无其他负载、无主动控制改变电流的模型：

```text
I(0) = V/R
P_R(0) = V²/R
tau = R×C
Vcap(t) = V×(1 − exp(−t/tau))
t_to_fraction_f = −R×C×ln(1−f), 0 < f < 1
E_cap(final) = 0.5×C×V²
E_resistor(total, complete charge) = 0.5×C×V²
E_resistor(to f) = 0.5×C×V²×[1−(1−f)²]
```

取示例 `V=58.8V, C=1000µF, R=100Ω, f=95%`：

| 项目 | 结果 |
|---|---|
| 初始电流 | 0.588A |
| 电阻初始功率 | 34.5744W |
| 时间常数 | 0.100s |
| 到 95% 的理想时间 | 约 0.299573s |
| 此时压差 | 2.94V |
| 完全充电电容储能/电阻累计耗能 | 各 1.72872J |

95% 只是计算示例，残余 2.94V 是否允许旁路取决于路径阻抗、开关应力和容差，不能自动当作合格阈值。电阻需按脉冲曲线和重复启动检查，不把 34.6W 峰值当连续功率，也不因总能量低就忽略瞬时应力。母线有初始电压、恒功率负载或预充期间控制电源取电时要改模型。

LTC7001 栅极 RC 控制 MOS 上升斜率的应用并不等于本算例的串联电阻 RC 充电；线性方案要另算 MOS 随时间的 VDS×ID 与 SOA。

## 4. 电容吸收回灌能量

在电容有效值近似恒定、仅考虑其储能差的模型中：

`Delta_E = 0.5 × C × (V_limit² − V_initial²)`。

例如仅为比较，`C=1000µF, V_initial=58.8V, V_limit=65V`，储能增加为 **0.38378J**。这里的 65V 是数学边界，绝不是批准本板或 63V 元件工作的上限。该算例说明“有大电解”不能在未算能量前代表回灌已解决；电机/负载惯量、制动过程、电源吸收和保护路径仍需建模。

## 5. MOS 与铜损

导通损耗采用单个器件实际电流波形及温度/驱动电压下的 RDS(on)。三相六管不默认各承担相 RMS，也不把冷态典型导通电阻用于最差热预算。

均匀铜段的 `I²R` 只反映该段电阻损耗；整板还包括端子、焊点、过孔、分流、MOS 开关与其他器件损耗。驱动供能 `Σ(Qg×Vdrive×f)` 也不等于驱动芯片自身全部发热。

所有最终计算附 `输入 → 来源 → 模型 → 结果 → 不确定性 → 布局/选型动作 → 验证`。不要从这些演示数值生成采购清单或整板额定。
