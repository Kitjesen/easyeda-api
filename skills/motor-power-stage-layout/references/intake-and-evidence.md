# 输入与证据

## 开始前建立一张表

从当前工程和已有对话取得信息；只有会影响下一步决定、又无法从文件取得的内容才需要用户补充。缺项不妨碍先检查明显错网、封装映射和机械冲突。

| 输入 | 记录内容 | 缺失时不能下的结论 |
|---|---|---|
| 目标设计 | 工程、原理图页、PCB UUID，版本/保存时间，网表与 PCB 同步关系 | 不能用旧工程截图宣布当前板已修复 |
| 输入电源 | 正常范围、满充上限、线缆、连接器、BMS 断开与吸收回灌的条件 | 不能仅用标称电压批准耐压和再生制动 |
| 电机与机械 | 电机型号、绕组接法、K_t 的电流定义、减速比/效率、轴端、转速、峰值时长和重复周期 | 不能把输出扭矩直接换成驱动电流 |
| 电流 | 相电流 RMS/峰值，电池平均/峰值，各工况的波形或模型 | 不能将电池电流填入相线、MOS 和低侧分流电阻的全部热预算 |
| 控制 | PWM 频率、调制方式、死区、采样时刻、最低有效采样窗口、保护延迟 | 不能只按静态 ADC 电压批准电流检测 |
| 器件 | 完整料号、封装修订、管脚、驱动电压、容值偏压曲线、分流额定条件 | 不能凭库符号名称和封装外形批准替换 |
| PCB | 层数、每层成品铜厚、介质、孔径/孔铜、铺铜和过孔实际几何 | 不能给确定的线宽、载流和热结论 |
| 热环境 | 环境温度、密闭程度、连续/脉冲工况、散热片、垫片、压紧与通风 | 不能把数据手册标准测试板热阻视为本板热阻 |
| 机械与制造 | 板框、孔位、接插件插拔、磁铁/编码器中心、高度、工艺选项 | 不能仅凭二维不重叠宣称可装配 |

表中每项标记 `已确认 / 有依据的假设 / 待确认`，附来源和日期。假设必须影响到计算结果的标注，不能仅在报告末尾泛泛注明。

## 真实引脚映射

对每相至少填写以下连接表。网络别名来自当前工程，不提前写死位号或脚号。

| 功能 | 必须确认的对象 |
|---|---|
| 上管 | MOS 实际 D/G/S 焊盘；并联引脚是否同网；散热焊盘电气属性 |
| 下管 | D 接哪一个相节点；S 接分流哪一侧；是否具有独立 Kelvin 源极 |
| 高侧驱动 | GH 到栅极；相应返回脚到源极取点；不得误用系统地 |
| 低侧驱动 | GL 与低侧参考脚真实连接；驱动地、采样负端、功率地的关系 |
| 电流检测 | 电阻力流端和测量端，前端 IN+/IN−，输出与 MCU ADC 通道 |
| 母线旁路 | 正端到上管供电端、负端到本地功率回流的真实路径 |
| 保护 | 栅极钳位、VDS 检测、故障输出和关断信号各自参考与默认态 |

器件有多个同名电源/源极焊盘时，不能只查符号中的一只脚。核查封装裸露焊盘、逻辑脚与物理脚的一致性。旋转/翻到底面后再确认方向和层镜像。

## 当前机器人项目的历史上下文

这些是 2026-09-08 整理时的用户已述条件，供后续核对，不是其他项目默认值：

- 14S 电池，满充 58.8V；2oz 和散热片是目标，各层及热界面尚未全部落实。
- 200N·m 为减速器输出短时峰值；电机未选定，不能据此给相电流额定。
- 直插/卧倒电解可接受，空间待定；两路编码器用于电机轴与减速器输出轴。
- 当前审查对象后来转为 STM32G431 工程。更早讨论过 GD32 主控、DRV8350S 和不同 MOS；是否仍在当前板上须回读 BOM。

没有现场 PCB 时，输出“布局约束/待查清单”；已有原理图只足以核对部分电气拓扑。截图可定位明显问题，不能精确推定铜厚、过孔网络或被其他层遮挡的连接。

## 参数冲突处理

优先核对当前工程和厂商准确型号/修订。参考板 README、历史设计说明、软件 Release 和 PCB 修订不是同一个版本对象；分别记录。使用社区文件时绑定提交和文件路径，区分“目录已收录”“源码已读”“已在本工具适配”“已在本板验证”。
