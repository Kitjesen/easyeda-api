# 当前限制与优先修复项

2026-09-08。本仓库迁移保存当前实现，以下问题没有因上传而被修复。

| 编号 | 证据与影响 | 当前状态 / 后续验收 |
|---|---|---|
| P0-01 | 当前 Bridge 返回路径引用未定义的 `activeWindowId`，实际变量为 `activeEdaWindowId`；静态源码确认 | 待修复。覆盖缺省与显式 windowId 请求，返回窗口必须属于该请求 |
| P0-02 | Bridge 的 30 秒超时删除 pending；迟到结果无法查询，客户端可能仍在写图 | 待实现持久化任务状态、迟到结果接收、重启后 unknown 保留；不能以 pending=0 判定空闲 |
| P0-03 | 核验层 finally 释放本地锁，不能让未知写入跨进程保持隔离 | 待实现与任务状态绑定的写入队列；恢复前核验已有对象与持久化结果 |
| P0-04 | 回包主要按请求 ID 匹配，未充分核对原请求所属窗口 | 待加 pending.windowId 与回包窗口匹配，跨窗口结果拒绝 |
| LIMIT-01 | `read` 模式可执行任意脚本，没有只读能力隔离 | 当前只供可信本地调用；未来提供受限参数的读取工具 |
| LIMIT-02 | 文件锁只约束本核验层，不能锁住用户界面或其他脚本 | 每次请求前后核对上下文；维护单一写图入口 |
| LIMIT-03 | 源码备份不包含完整工程；无原子事务和自动回滚 | 保存、全工程导出、网表与图面证据分别记录 |
| LIMIT-04 | 3.2.186 客户端不能被当作拥有文档中所有 4.2 API | 每项功能探测运行时并实测；原生 DRC 异常不能由包装层声明解决 |

P0-01 至 P0-04 是本地源码静态审计结论，未在本轮制造现场故障。具体来源和改进路线见 [API 路线图](../api-roadmap-20260908/API增强路线图.md)。
