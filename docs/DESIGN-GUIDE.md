# API 与原理图设计指导

本文件约束后续工具实现，来自当前协作中出现过的问题；详细历史见 [原理图设计指导](../stm32g431-review-20260907/原理图设计指导.md)。

原理图整体排版、标签移动和现场 API 修改同时阅读[原理图排版、写入与验收注意事项](SCHEMATIC-EDITING-NOTES.md)。其中记录完整对象组移动、NET 电气含义、显示字段规范化、超时恢复和最新原生导出的判定方法。

PCB 工作需同时阅读 [PCB 专题](../pcb-knowledge/README.md) 和 [PCB 设计指导](../pcb-knowledge/PCB-DESIGN-GUIDE.md)，以功率回路、真实机械/制造条件和实际器件为约束。仅靠原理图排版规则或通用自动布线参数不足以完成电机板设计。

电机功率级任务进一步使用 [motor-power-stage-layout](../skills/motor-power-stage-layout/SKILL.md)，按模块读取详细规则和验收条件。检查结果需定位到实际位号/焊盘/网络/层，不以“紧凑”“整齐”替代电气证据；每项数值约束标明来源和适用条件。

## 一次修改的完整流程

1. 读取唯一窗口、工程 UUID、图页 UUID、实际 API 能力。记录当前版本和原始图面。
2. 取得真实器件身份、封装、引脚坐标和网表。把期望连接写成引脚到网络的表，保留明确 NC。
3. 生成限定对象范围的计划及源码哈希。保留 Device、Unique ID、位号、采购料号和 PCB 关联。
4. 先计算紧凑布局和短实线，检查端点、标签外框、重复段和交叉点。模块之间用必要的标签/端口。
5. 经同一入口写入一次；执行状态未知时停止新的依赖写入，读取现场确认。禁止按超时次数重复创建。
6. 用独立请求检查实际属性和引脚网络，再保存、重新读取/导出，检查正常字号图面。分别记录官方 DRC 与独立检查。

## 图面规则

- 同一芯片的阻容、钳位、上拉下拉围绕对应引脚成组；去耦和反馈回路近邻排列。
- 信号通常从左到右，电源在上、地在下。先定器件位置，再生成正交短线；不以长线把散落器件串起来。
- 标签的方向、锚点和外框须避让器件主体、位号、参数、引脚和相邻标签。字号/单位从当前图页的正常实例读取，不猜缩放比例。
- 模块内部能清楚直连时用短实线。删除完全重复、零长和无意义折返线；不能仅因交叉看似重合就认定相连。
- 同一类三相或双编码器模块使用一致间距与方向；先调整一个模块并验证，再推广。
- 排版修改前后比较引脚连接集合，避免删标签后改网名或意外短接。截图好看不等于网表正确。

## 防止设计过度复杂

先把需求列成必要功能和故障行为，再确定每个器件的职责。预充的驱动、限流、母线压差判定和超时状态机分别有明确承担者；LTC7001 是高侧栅极驱动器，不能仅凭单芯片名称假设已具备全部判断逻辑。可由 MCU 承担的逻辑应评估上电默认态、失控条件与必要硬件保护后精简。增加器件需说明可验证的用途。

## 版本、证据和错误积累

上游客户端、Gateway、Bridge/Skill、包依赖和本地补丁分别记录版本。社区代码按固定提交读取；先做适配测试，再进行隔离工程实测。每个新错误追加 [错误记录](ERROR-LOG.md)，含现象、确认原因、影响范围、修正、验证、未完成项。不要把调研项批量改为已完成。

## 按完整参考回路划分 AGND

AGND 是模拟参考网络的名称；0Ω 连接件用于受控连接和调试，不自动提供隔离或滤波。不能按“运放、电容属于模拟器件”批量改地，应从准确封装引脚、测量零点和完整回流逐项判断：

- ADC/VSSA、模拟电源去耦、前端供电地、滤波/钳位返回与参考源回路协调；比例测量还需核对分压激励和 ADC 参考是否同源。
- 低侧分流放大器的 IN+/IN− 按真实分流端取样，不能因前端供电地迁到 AGND 就把感测端从分流器移走。
- 开关电源反馈、功率旁路与栅极放电参考自身局部返回；数字指示灯等负载不借模拟参考回路返回。
- MCU 各地脚必须保持符合器件要求的可靠低阻连接。是否分地铜、连接位置和回流转换由实际 PCB 路径决定，三个网名和一颗 0Ω 不能证明地弹受控。

修改前列出精确迁移引脚，修改后比较所有其他引脚连接分区和物料身份。参考工程也要分别读取图面、实际网表和 BOM；示意计算图元不一定是装配器件，图面名称异常不能作为本板改网的依据。PCB 细则见 [采样与回流](../skills/motor-power-stage-layout/references/sensing-and-ground.md)。

## 分清主板和并联节点的职责

先建立电池/BMS、主板、支路与关节板的实际电源树，再分配启动浪涌、反向电流、过欠压、短路、瞬态钳位和相级保护。主板已有集中输入控制与 ORing 时，不在每块节点机械复制同类控制器；确有独立热插拔或选择性保护要求时，再按该需求论证。

集中能力按总输入电容、并发启动、总电流、线束寄生、故障切断与外部 MOS SOA 核验。删除节点的重复控制器时，逐项保留仍承担局部职责的电容、支路保护、瞬态钳位及相级快速关断。

电源串接线束可以让各板电气并联。贯通插座和铜路应按下游累计电流核算；只位于本板取电支路的保险丝不能代表贯通路径也获得同等保护。接口的固定焊脚不是线束地芯，通信参考路径要按真实接插件及整机供电返回检查。

ORing 的方向控制、BMS 能否接受回灌和再生能量耗散是独立问题。反向阻断会改变能量路径，不能仅凭器件名称认定已具备制动吸能能力；TVS 也不能未经能量与重复率核算就承担持续制动负载。资料和系统工况不全时保留未决输入，不填写臆测的额定值。

## 将未决事项写成 PCB 要求和实测计划

原理图修改完成后，为后续 PCB 建立一份版本明确的要求文档，另建实测计划；二者用稳定编号互相引用。PCB 文件描述如何实现并如何审核，实测文件描述如何取得波形、温度或功能证据。参考 [执行与验收专题](../skills/motor-power-stage-layout/references/review-and-easyeda.md)，不要把“注意回流”“实测一下”作为可执行交付。

| 文档 | 每项至少包含 | 例子与完成依据 |
|---|---|---|
| PCB 设计要求 | 编号、实际位号/焊盘/网络、必须实现的约束、判据来源、需要提交的图或计算、状态 | 分流器两端 Kelvin 取点，提交各层取样路径；ECO 后器件 UID、封装脚与最终网表一致 |
| 实测验证计划 | 编号、版本/前提、测点及返回、仪器条件、执行步骤、原始数据、判据与停止条件、状态 | 量 MOS G-S 差分波形、PWM 到 ADC 建立时间、实际温升；保存工况和原始波形 |

先断电核对版本与装配，再在限能条件下确认电源和默认关断，之后逐级验证开关、测量、通信、运动及功率负载。主板/BMS/整串再生列为系统级项目；单板通过不能推断整机通过。电压、电流、持续时间和温度限值来自实际器件及预算，未知条件保持待定。

实测初始状态统一为“未测”；仿真、计算、DRC 和主机软件测试不改变该状态。PCB 未同步、固件未集成、样机未装配分别记录。后续原理图换件或换脚时同步更新两份文档的当前版本和测点，历史结果保留其适用基线。
